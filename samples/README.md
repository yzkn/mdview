# samples

**目で見ないと確かめられないもの**を確認するための文書を置く。

自動試験は「記法が消えていること」「役割が付いていること」までは確かめられるが、
**字形が正しいか・色が読みやすいか**は判定できない。ここはその穴を埋める。

|文書|用途|
|---|---|
|[p3-check.md](p3-check.md)|P3（埋め込み）の目視確認。字形・インライン要素・着色・表・折り返し|

## 使い方

```
target\release\mdview.exe samples\p3-check.md
```

**Split（既定）で開き、左右を見比べる。** 文書の各節に「確認すること」を
書いてあるので、上から順に見ていく。

## 注意

**README.md で着色を確かめてはいけない。** `powershell` と `text` は
syntect の既定構文に無く、着色されるのは 1 行の `bash` だけである。
「着色が効いていない」と誤って判断する（実際に起きた）。
