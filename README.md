# mdview

**10MB の Markdown を開いて、読んで、書ける**デスクトップアプリ。
Rust 単一言語で、WebView を使わずに描いている。

- **単一の実行ファイル**。ランタイムの導入は要らない
- **日本語の字形が崩れない**。フォントを同梱し、環境のフォント選択に依存しない
- **10MB でも待たされない**。全文を毎回組み直さず、見えているところだけ測る
- **UTF-8 以外も開ける**。Shift_JIS / EUC-JP / JIS / UTF-16 を判定して開く
- PDF と HTML に出力できる（目次・しおり・図・数式・画像を含む）
- **2 つの文書を比べられる**。左右とも直せ、パッチを作る・当てることもできる。フォルダーの比較・3 つのファイルのマージもある
- **Marp のスライド**を見せ、発表し、PDF / HTML / PPTX（PowerPoint で文字を直せる）に書き出せる
- **MCP サーバー**として動く。MCP クライアント（AI のアプリなど）から、操作ごとに許可・確認・拒否を決めて文書を読み書きさせられる
- **WYSIWYG で直せる**。記法を見せずに描いた文字の上で打つ。裏では原文を書き換え、触っていない所の書き方は変えない

Windows / macOS / Linux で動く。

## 入れる

[Releases](../../releases) から落とす。**どれも単体で動く。**

|OS|入れて使う|そのまま動かす|
|---|---|---|
|Windows 10/11 (x64)|`mdview-<版数>-windows-x86_64-setup.exe`|`mdview-<版数>-windows-x86_64.exe`|
|macOS 11+ (Apple Silicon)|`mdview-<版数>-macos-aarch64.dmg`|`mdview-<版数>-macos-aarch64`|
|Linux (x64)|`mdview-<版数>-linux-x86_64.deb`|`mdview-<版数>-linux-x86_64.AppImage`|

Linux 版は **glibc 2.39 以上**が要る（Ubuntu 24.04・Debian 13 以降。Ubuntu 22.04・Debian 12 では起動しない）。

> **署名していない。** 初回起動時に OS の警告が出る。外し方は Release の
> 説明文にある。署名の代わりに SHA-256 の照合値を添えている。

## 使う

```
mdview [オプション] [開くファイル…]
```

|オプション|効き目|
|---|---|
|`-g`, `--goto <行>`|その行（1 始まり）を開く。行が足りなければ最終行|
|`-r`, `--readonly`|読み取り専用で開く（本文も元のファイルも書き換えない）|
|`-t`, `--always-on-top`|常に最前面で開く（設定より優先する。設定は変えない）|
|`--url <URL>`|URL の Markdown を読み取り専用で開く（v2.4.0）|
|`--mcp`|MCP サーバーとして動く（窓は出さない。MCP クライアントから標準入出力で呼ぶ。v2.4.0）|
|`-v`, `--version`|版数を出す|
|`-h`, `--help`|使い方を出す|

```
mdview -r -g 120 notes.md     # 120 行目を、読み取り専用で開く
```

**読み取り専用**は表示メニューからも切り替えられる。打つ・貼る・上書き保存を断り、
ステータスバーと題名に「読み取り専用」と出る。名前を付けて保存はできる。

> **Windows の端末からは `mdview`（拡張子無し）と打つ。** インストーラが入れる
> 端末用の入口 `mdview.com` が起き、端末は答えが出るまで待つ。`mdview.exe` は窓の
> アプリなので、拡張子まで打つと版数がプロンプトの後ろに出ることがある。

**キーは設定画面（キー割り当て）で変えられる。** 表示の切り替え（編集・プレビュー・
分割）・目次・常に最前面・読み取り専用・ファイルを比べる・目次を入れる・Markdown の検査の一覧
などには既定のキーが無いので、使うならそこで割り当てる。メニューの項目はすべて割り当てられる。

メニューは `Alt` + 下線の文字で開く（`Alt + F` でファイル）。
開いている間は、文字だけで項目を選べる。

**スクロールバーは掴んで動かせる。** 溝を押すとその位置へ飛ぶ。
エディタは縦と横、プレビューは縦に出る。

### 設定とウィンドウ（v2.1）

- **設定画面**（ファイル → 設定…、`Ctrl + ,`）。ウィンドウ・エディタ・プレビュー・外観・
  ファイル・編集補助・キー割り当ての 7 分類（v2.3 でスニペット・比べる、v2.4 でスライド・MCP を足して 11 分類）。変えたものはその場で効き、自動で保存され、
  開いている他の窓にも効く
- **ミニマップ**（エディタの縦のスクロールバーが文書の縮図になる。見出し・検索の一致・
  キャレットに印が付く）
- **常に最前面に表示**（表示メニュー）と、**起動時の窓の置き方**（中央・前回の位置・
  画面の左半分／右半分・最大化 など）
- **新しいウィンドウ**。起動時に 2 つ以上のファイルを渡すと、2 つ目からは別の窓で開く
- **読み取り専用**（表示メニュー、または起動オプション `-r`）
- **外で書き換えられたら知らせる**（未編集なら確かめずに読み直す設定もある）・
  **自動保存**（既定は切ってある）

### v2.4 で足したもの

- **背景画像**（設定 → 外観）。本文の後ろに好きな画像を敷く。敷く所（既定は編集画面とプレビューにそれぞれ 1 枚）・
  並べる・伸ばす・収める・覆う・原寸・配置 9 か所を選べ、濃さとぼかしは明るい配色・暗い配色で別々に決める。
  本文と一緒に動かすこともできる。PDF・HTML には入らない
- **コマンドパレット**（`Ctrl + Shift + P`）。メニューにある操作を名前で絞り込み、Enter で実行する。
  ひらがなとカタカナ・大文字小文字・空白の違いは無視する。いま使えない操作は薄く出す。最近使った操作を上に出す
- **プレビューから編集画面の行へ飛ぶ**（段落・見出し・表・コードブロックをダブルクリック。Alt + クリック・
  Ctrl + クリックにも変えられる）と、分割表示で**キャレットを追ってプレビューを送る**。設定 → プレビュー
- **図を拡大して見る**。Mermaid の図・数式・画像をダブルクリックかボタンで開き、ホイールで拡大・縮小、引いて動かす。
  図と数式は大きく描き直すのでにじまない。**PNG としてコピー・保存**できる（図と数式は既定で 2 倍）
- **コードブロックを写す**。ポインタを置くと右上に出るボタンで、前後の ``` を除いたコードを写す
- **Mica 風の窓の地**（Windows）。デスクトップの壁紙を強くぼかして窓の地に敷く。後ろの窓は透けない
  （iced 0.14 は Windows で窓を透かせないので、見た目を自前で描く）。設定 → 外観で不透明に戻せる。ほかの OS は不透明
- **MCP サーバー**。MCP クライアント（AI のアプリなど）から `mdview --mcp` を起こすと、窓を出さずに標準入出力で MCP を話す。
  文書を読む・構造（見出し・リンク・frontmatter など）・検査・パッチ・目次・番号に加え、開いている窓の本文の読み書き・
  検索と置き換え・保存・出力・URL を開くなど、29 の道具がある。窓の書き換えは元に戻すで 1 回で戻る
  - **操作ごとに許可・確認・拒否**を決められる（設定 → MCP）。既定は、保存・出力・全文の置き換え・閉じる・
    設定を変えるなど壊しうる操作が「確認」で、相手の窓にダイアログを出して聞く。MCP 自身の設定は MCP からは変えられない
  - **手元の HTTP** でも受けられる（既定は受けない）。`http://127.0.0.1:<口>/mcp` だけで待ち、ほかの PC からはつなげない。
    呼ぶ側は合言葉（受け始めるたびに作り直す）を `Authorization: Bearer` で付ける
- **Marp のスライド**。frontmatter に `marp: true` があると、プレビューを 1 枚ずつ 16:9（か 4:3）の枠で見せる。
  テーマは `default`・`gaia`・`uncover` に近いもの。`paginate`・`header`・`footer`・`class`・背景の画像（`![bg](…)`）などの指示が効く。
  Marp と同じ見た目にはならない
  - **指示を補う**。frontmatter と `<!--` の後ろで指示の名前と値の候補を出し、指示の間違い（MP001〜MP007）を検査する
  - **発表**（`F5`）。キャレットのあるスライドから全画面で 1 枚ずつ見せる。`Esc` で終わる
  - **書き出す**。PDF（1 枚 1 ページ）・HTML（1 枚を 16:9 の箱）・**PPTX**（v2.7 から PowerPoint で文字を直せる）。
    コマンドラインの `--export-pptx` もある。設定 → スライド
- **URL を開く**（`Ctrl + Shift + L`、ファイルメニュー）。URL の Markdown を**読み取り専用**で開く。GitHub・GitLab・gist の
  画面の URL は中身の URL に読み替える。最近開いた URL から選べる。URL の画像は設定 → ファイルの「画像も URL から取る」を
  入れたときだけ取る（既定は切る）。中継（プロキシ）は環境変数 `HTTPS_PROXY` などに従う
- WYSIWYG 編集は次の版（v2.5）へ回した

### v2.3 で足したもの

- **2 つの文書を比べる**（ファイルメニューの「ファイルを比べる…」「保存してある元と比べる」）。左右に並べ、
  違う行・片側にだけある行・行の中で違う文字を色分けし、向かい側に空きの段を挟んで高さを揃える。
  **左右とも直接書き換えられ**、書き換えると比べ直す。`F7` / `Shift + F7` で次・前の違いへ、写す・左右の入れ替え・
  1 列表示もある。空白・大文字小文字・改行コードの違いは無視できる（設定 → 比べる）
- **パッチを作る・当てる**（unified と context。当てるときは形式を中身から見分ける）。GNU diff / patch と行き来できる
- **編集画面の記法の色**（見出し・強調・コード・リンク・引用・リストや表の印）。設定 → エディタで切れる
- **自分の配色**（元にするプリセットを選び、変えたい色だけを `#RRGGBB` で書く。設定 → 外観）と、
  **日の出・日の入りで明るい・暗いを切り替える**（ネットにつながず計算。場所と、ずらす分数を決められる）
- **目 grep**。決めた文字列（ただの文字列か正規表現）が出てきたところを、編集画面とプレビューで塗る
- **列番号**（編集画面の上の目盛りと、指定した桁の縦線）。設定 → エディタ
- **コードスニペット**。略語を打って `Tab`、または `Ctrl + Shift + J` で一覧から入れる。入力位置は `Tab` で移る。
  設定 → スニペットで足す・直す
- **目次を入れる・作り直す**（`<!-- TOC -->` の間だけ）、**見出しに番号を振る・外す**（番号を振った文書は保存のたびに振り直す）
- **Markdown の検査**（markdownlint の規則のうち 17 個）。波線を引き、表示メニューの「Markdown の検査の一覧」で
  一覧にし、直し方が 1 つに決まるものはその場で直せる
- **光と影**（Fluent Design）。ダイアログとメニューを、角を丸め柔らかい影を付けた面にそろえた
- **集中モード**（`F11`）。全画面にしてメニュー・ステータスバー・目次・ミニマップなどを隠し、本文だけにする。
  もう一度か `Esc` で戻る。OS の通知は止めない
- 起動直後の窓は既定で画面の中央に出る

### v2.2 で足したもの

- **窓の題名とステータスバーの書式**（設定 → 外観）。`{name}` `{path}` `{type}` `{dirty}` `{state}`
  `{line}` `{col}` `{encoding}` `{size}` `{date:yyyy-mm-dd ddd}` `{time:hh:mm:ss}` などの差し込み口で組む。
  `{date}` の `mm` は月、`{time}` の `mm` は分。既定の書式は v2.1 までの表示と同じ
- **右端で折り返す**（設定 → エディタ。**512 KB 以下のファイルだけ**）。上下の矢印は見た目の段で動く
- **テキストやソースファイルも開ける。** 拡張子が `.md` / `.markdown` でなければ Markdown として読まず、
  そのまま等幅で並べる（言語ごとの色付けは無い）
- **右クリックのメニューの「mdview で開く」**（Windows のインストーラ。`.md` / `.markdown`）
- **プレビューで文字を選べる**（ドラッグで選び、`Ctrl + C` で表示されている文字を写す）
- 新規作成した文書は空で始まる

### 編集の補助（v2.1）

- **移動メニュー**: 定義・型定義・宣言・実装へ移動、参照を探す、閉じ括弧へ移動、
  見出しへ移動（絞り込み）、リンクを開く、リンク切れを検査、見出しの折りたたみ
- **行コメント・ブロックコメントの切替**（コードブロックの中では、その言語の書き方になる）
- **書式**（太字・斜体・インラインコード・リンク）
- **`Enter` でリストと引用を続ける**。中身の無い項目で押すとリストを抜ける
- **表の整形**と、表に行・列を足す
- **URL を選んだ文字の上へ貼るとリンクになる。** 画像を貼る・画像のファイルを落とすと
  文書の隣の `images/` に保存して入れる

### 編集

取り消し・やり直し、範囲選択、矩形選択のほか、行の複製・削除・連結、
字下げ、大文字小文字・全角半角・ひらがなカタカナ・タブ↔空白の変換、
日付・時刻の挿入、対応する括弧へのジャンプができる。

検索・置換は**正規表現**と大文字小文字の区別に対応する。

### ファイルを開く

**ふだんは OS のダイアログを使う。** ただし Linux のダイアログは
xdg-desktop-portal（D-Bus）越しにしか出せず、**WSL の既定の環境には
どちらも入っていない。** そういう環境では**アプリの中の選択**へ
自動で切り替わる。

いつでも使いたいときは、ファイルメニューの「アプリ内で開く…」から。
`MDVIEW_IN_APP_PICKER=1` を立てると、常にそちらになる。

### 文字コードと改行コード

開いたときの形（文字コード・BOM・改行）を**そのまま保存に戻す**。
開いて保存しただけで差分が出ることはない。

変えたいときはファイルメニューから指定する。

|選べるもの|
|---|
|UTF-8（BOM あり / なし）/ Shift_JIS / EUC-JP / JIS / UTF-16LE / UTF-16BE|
|LF / CRLF|

判定が外れたときは「文字コードを指定して開き直す」で直す。

### 見えない文字

Web や Office から貼り付けると、**見えないのに悪さをする文字**が紛れ込む
ことがある（ゼロ幅スペース、BOM、ノーブレークスペース、書字方向の制御文字
など）。これらに赤い枠を出す。**既定で有効**——気づく前に保存させないため。

空白・タブ・改行の印は、表示メニューから出せる。
**改行の印は改行コードで形が変わる**（`CRLF` は `↵`、`LF` は `↓`）。

## 書ける記法

GitHub Flavored Markdown（見出し・表・チェックリスト・コードブロック）に加えて、

- **コードの色分け**（言語指定のあるコードブロック）
- **Mermaid の図**（```` ```mermaid ````）
- **数式**（```` ```math ````。LaTeX）
- **ローカル画像**（`![説明](path.png)`）

生の HTML は**表示せず、原文のまま**出す。ただし **`<img>` タグ 1 つだけの段落**は画像として描く（GitHub と同じ書き方。`width` の指定も効く）。

## 作る

```
python tools/fetch-fonts.py                 # 同梱フォント（初回のみ）
cargo run --release --example make-icons    # アイコン
cargo build --release
```

同梱フォントとアイコンはリポジトリに置いていない（フォントは 21.56MB ある）。
取得先と照合値は `tools/fetch-fonts.py` に、アイコンの原本は `assets/*.svg` にある。

Rust の版は `rust-toolchain.toml` で固定している。

配布物を組むスクリプトは [`packaging/`](packaging/) にある。
通常は GitHub Actions が組む。
