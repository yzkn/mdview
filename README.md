# mdview

**10MB の Markdown を開いて、読んで、書ける**デスクトップアプリ。
Rust 単一言語で、WebView を使わずに描いている。

- **単一の実行ファイル**。ランタイムの導入は要らない
- **日本語の字形が崩れない**。フォントを同梱し、環境のフォント選択に依存しない
- **10MB でも待たされない**。全文を毎回組み直さず、見えているところだけ測る
- **UTF-8 以外も開ける**。Shift_JIS / EUC-JP / JIS / UTF-16 を判定して開く
- PDF と HTML に出力できる（目次・しおり・図・数式・画像を含む）

Windows / macOS / Linux で動く。

---

## 入れる

[Releases](../../releases) から落とす。**どれも単体で動く。**

|OS|入れて使う|そのまま動かす|
|---|---|---|
|Windows 10/11 (x64)|`mdview-<版数>-windows-x86_64-setup.exe`|`mdview-<版数>-windows-x86_64.exe`|
|macOS 11+ (Apple Silicon)|`mdview-<版数>-macos-aarch64.dmg`|`mdview-<版数>-macos-aarch64`|
|Linux (x64)|`mdview-<版数>-linux-x86_64.deb`|`mdview-<版数>-linux-x86_64.AppImage`|

> **署名していない。** 初回起動時に OS の警告が出る。外し方は Release の
> 説明文にある。署名の代わりに SHA-256 の照合値を添えている。

## 使う

```
mdview [開くファイル]
```

### キー割り当て

|操作|キー|
|---|---|
|新規 / 開く / 保存|`Ctrl + N` / `O` / `S`|
|名前を付けて保存|`Ctrl + Shift + S`|
|取り消し / やり直し|`Ctrl + Z` / `Ctrl + Y`|
|切り取り / コピー / 貼り付け|`Ctrl + X` / `C` / `V`|
|すべて選択|`Ctrl + A`|
|**矩形選択**|`Alt` + ドラッグ|
|検索・置換|`Ctrl + F`（`Enter` 次へ / `Shift + Enter` 前へ / `Esc` 閉じる）|
|行の複製 / 削除 / 連結|`Ctrl + D` / `L` / `J`|
|字下げ / 戻す|`Tab` / `Shift + Tab`|
|指定行へジャンプ|`Ctrl + G`|
|対応する括弧へ|`Ctrl + ]`|
|語の単位で移動|`Ctrl + ←` / `→`|
|文書の先頭 / 末尾|`Ctrl + Home` / `End`|
|Edit / Preview / Split|`Ctrl + 1` / `2` / `3`|
|目次の表示切替|`Ctrl + B`|
|拡大 / 縮小 / リセット|`Ctrl` + `+` / `-` / `0`|
|横へ送る|`Shift` + ホイール（長い行は折り返さない）|
|アプリ内のファイル選択|ファイルメニュー →「アプリ内で開く…」|

メニューは `Alt` + 下線の文字で開く（`Alt + F` でファイル）。
開いている間は、文字だけで項目を選べる。

**スクロールバーは掴んで動かせる。** 溝を押すとその位置へ飛ぶ。
エディタは縦と横、プレビューは縦に出る。

### 編集

取り消し・やり直し、範囲選択、矩形選択のほか、行の複製・削除・連結、
字下げ、大文字小文字・全角半角・ひらがなカタカナ・タブ↔空白の変換、
日付・時刻の挿入、対応する括弧へのジャンプができる。

検索・置換は**正規表現**と大文字小文字の区別に対応する。

### ファイルを開く

**ふだんは OS のダイアログを使う。** ただし Linux のダイアログは
xdg-desktop-portal（D-Bus）越しにしか出せず、**WSL の既定の環境には
どちらも入っていない。** そういう環境では**アプリの中の選択**へ
自動で切り替わる。

いつでも使いたいときは、ファイルメニューの「アプリ内で開く…」から。
`MDVIEW_IN_APP_PICKER=1` を立てると、常にそちらになる。

### 文字コードと改行コード

開いたときの形（文字コード・BOM・改行）を**そのまま保存に戻す**。
開いて保存しただけで差分が出ることはない。

変えたいときはファイルメニューから指定する。

|選べるもの|
|---|
|UTF-8（BOM あり / なし）/ Shift_JIS / EUC-JP / JIS / UTF-16LE / UTF-16BE|
|LF / CRLF|

判定が外れたときは「文字コードを指定して開き直す」で直す。

### 見えない文字

Web や Office から貼り付けると、**見えないのに悪さをする文字**が紛れ込む
ことがある（ゼロ幅スペース、BOM、ノーブレークスペース、書字方向の制御文字
など）。これらに赤い枠を出す。**既定で有効**——気づく前に保存させないため。

空白・タブ・改行の印は、表示メニューから出せる。
**改行の印は改行コードで形が変わる**（`CRLF` は `↵`、`LF` は `↓`）。

## 書ける記法

GitHub Flavored Markdown（見出し・表・チェックリスト・コードブロック）に加えて、

- **コードの色分け**（言語指定のあるコードブロック）
- **Mermaid の図**（```` ```mermaid ````）
- **数式**（```` ```math ````。LaTeX）
- **ローカル画像**（`![説明](path.png)`）

生の HTML は**表示せず、原文のまま**出す。

## 作る

```
python tools/fetch-fonts.py                 # 同梱フォント（初回のみ）
cargo run --release --example make-icons    # アイコン
cargo build --release
```

同梱フォントとアイコンはリポジトリに置いていない（フォントは 21.56MB ある）。
取得先と照合値は `tools/fetch-fonts.py` に、アイコンの原本は `assets/*.svg` にある。

Rust の版は `rust-toolchain.toml` で固定している。

配布物を組むスクリプトは [`packaging/`](packaging/) にある。
通常は GitHub Actions が組む。
